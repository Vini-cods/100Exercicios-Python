# 100 Exercícios de Python

Este repositório reúne uma série de exercícios práticos de Python, organizados em módulos para facilitar o aprendizado progressivo da linguagem. A ideia foi construir uma base sólida em lógica de programação, entrada e saída de dados, operações matemáticas, condicionais e estrutura de scripts simples.

O objetivo principal foi praticar os conceitos básicos de Python de forma direta, escrevendo pequenos programas independentes, testando resultados no terminal e entendendo como cada instrução funciona na prática.

---

## Sobre o projeto

Aqui você encontra exercícios focados em:

- leitura e escrita de dados com `input()` e `print()`
- conversão de tipos (`int()`, `float()`, `str()`)
- variáveis e operadores aritméticos
- uso de estruturas condicionais (`if`, `elif`, `else`)
- lógica de programação aplicada a problemas simples e cotidianos
- organização por módulos e por níveis de dificuldade

O repositório foi pensado como um ambiente de estudo, então cada arquivo é um exercício separado e pode ser executado de forma independente.

## Módulo 01 — fundamentos da linguagem

O primeiro módulo concentra os exercícios iniciais de Python. Ele foi o ponto de partida para aprender a sintaxe básica da linguagem e a lógica mais simples de programação.

Nessa parte, os programas trabalham com:

- entrada de dados via terminal
- variáveis e operações matemáticas
- conversão de valores
- cálculos de soma, média, desconto e reajuste
- uso de `print()` para mostrar resultados
- noções básicas de organização do código

### Exercícios incluídos no módulo 01

- Exercício 01: soma de dois números
- Exercício 02: cálculo de média simples
- Exercício 03: antecessor e sucessor
- Exercício 04: dobro, triplo e metade
- Exercício 05: conversão de metros para centímetros e milímetros
- Exercício 06: cálculo de área e perímetro de um retângulo
- Exercício 07: conversão de Celsius para Fahrenheit
- Exercício 08: aplicação de desconto em um produto
- Exercício 09: reajuste de salário
- Exercício 10: cálculo de comissão de vendas
- Exercício 14: troca de valores entre variáveis
- Exercício 15: cálculo de compra com frete

Esse módulo foi essencial para consolidar a base da linguagem, principalmente em relação à leitura de dados do usuário e ao processamento de informações.

---

## Módulo 02 — estruturas condicionais e tomada de decisão

A partir do exercício 16, o foco muda para a lógica condicional. Esse módulo é voltado para problemas em que o programa precisa decidir entre diferentes caminhos com base em condições.

Aqui foram praticados:

- `if`
- `elif`
- `else`
- comparação de valores
- identificação de sinais de números
- validação de regras de negócio simples
- resolução de problemas com estrutura de decisão

### Exercícios incluídos no módulo 02

- Exercício 16: positivo, negativo ou zero
- Exercício 17: par ou ímpar
- Exercício 18: maior entre dois números
- Exercício 19: desconto por faixa de valor
- Exercício 20: dia da semana
- Exercício 21: validação de senha
- Exercício 22: triângulo pelo ângulo
- Exercício 23: calculadora com tratamento de erros
- Exercício 24 a 35: continuação da prática com lógica condicional e exercícios mais elaborados

Esse módulo foi importante porque introduziu uma parte mais profunda da programação: além de calcular, o programa agora precisa tomar decisões com base em condições.

## Observações

- Os arquivos estão organizados por módulo e por sequência numérica.
- O estudo foi feito de forma gradual, começando pelo básico até chegar em estruturas condicionais mais ricas.
- Há também um arquivo `if.py`, usado como apoio para praticar e testar a lógica de condicionais em um contexto mais simples.
- O arquivo `Fluxogramas.pdf` complementa a parte visual do aprendizado, ajudando a entender a lógica por diagramas.

---

## Objetivo do projeto

Este repositório representa um passo importante no aprendizado de Python, mostrando como a lógica de programação vai evoluindo desde operações simples até decisões e validações mais complexas.

Cada exercício foi pensado como um desafio pequeno, mas com propósito: transformar conceitos teóricos em prática real, no terminal, resolvendo problemas concretos.
